Encoder

- get_embedding - returns the learned embedding representation without using the final classifier.

- prepare_data - selects numeric features, removes invalid values, converts labels to arrays, scales the features, and prepares the training and testing data

- get_feature_columns - finds all numeric input columns except the label column

- train - creates training batches and trains the neural network using cross-entropy loss and the Adam optimizer

- predict - predicts the class labels for one or more input samples

- predict_one - predicts the class label for a single sample

- get_test_data - returns the prepared test features and test labels

- save_model - saves the trained model, model settings, selected features, and scaler information to a file

Proto 

constructor - creates the protonet embedding network and stores the input, hidden, and embedding sizes

forward - passes input samples through the embedding network

calculate_prototypes - calculates the mean embedding for each class to create its prototype

calculate_distances - calculates the squared euclidean distance between query embeddings and class prototypes

episode_loss - performs one protonet training episode and calculates the cross-entropy loss

create_targets - converts the original class labels into prototype positions used by the loss function

predict_from_prototypes - predicts each sample by finding the nearest class prototype

embedding - transforms the original network traffic features into a smaller learned representation

support embeddings - embeddings created from the support samples

query embeddings - embeddings created from the query samples

prototypes - average embeddings representing each class

distances - measures how close each query sample is to each class prototype

logits - negative distances used by cross-entropy loss so closer prototypes receive higher scores

MAML
Constructor - creates the MAML neural network and stores settings such as input size, number of classes, hidden size, embedding size, inner learning rate, inner steps, and whether to use first-order MAML.

forward - passes network traffic features through the neural network to produce classification scores for each attack class.

network - defines the neural network architecture using linear layers and ReLU activation functions.

adapt - performs the inner training loop using support samples to update temporary model parameters for a specific few-shot task.

inner loop - adapts the model to the support samples using gradient descent. The original model parameters are not directly replaced.

inner_lr - controls how much the temporary model parameters change during each adaptation step.

inner_steps - determines how many gradient updates are performed during adaptation.

functional_call - runs the neural network using temporary adapted parameters instead of its original parameters.

support_x - contains the network traffic features used to adapt the model.

support_y - contains the attack class labels for the support samples.

query_x - contains the network traffic features used to evaluate the adapted model during meta-training.

query_y - contains the correct attack labels for the query samples.

query_loss - calculates the cross-entropy loss between the adapted model's predictions and the correct query labels.

meta_train_step - performs one outer-loop training update using multiple few-shot episodes.

outer loop - updates the original model parameters using the query losses calculated after adaptation.

meta_loss - calculates the average query loss across all episodes in the meta-batch.

first_order - determines whether MAML uses first-order or second-order gradients. First-order MAML requires less computation and memory.

predict - predicts attack classes using either the original model parameters or adapted parameters.

logits - classification scores generated by the network for each attack class.

cross-entropy loss - measures the difference between predicted attack classes and their correct labels.

model parameters - the neural network weights that MAML learns so the model can adapt quickly to new tasks.

MAML Runner

Constructor - stores MAML experiment settings such as shot size, query size, test size, random seed, hidden size, embedding size, inner learning rate, outer learning rate, inner steps, meta-batch size, meta-epochs, and first-order setting.

run - runs the full MAML experiment from dataset preparation through episodic training, evaluation, and saving.

prepare_data - loads the selected dataset, cleans it, encodes attack labels, prepares the training and testing datasets, and scales the input features.

dataset splitting - creates or retrieves the training and testing partitions. CIC-IDS2017 uses a stratified 80/20 training and testing split. UNSW-NB15 uses its existing training and testing CSV files.

get_feature_columns - identifies the input features used by MAML. In the current implementation, feature selection is performed inside prepare_data, rather than through a separate method.

categorical encoding - converts categorical network traffic features into numeric values using one-hot encoding.

feature scaling - standardizes numerical features using statistics calculated from the training dataset.

label_mapping - converts attack class labels into consecutive integer values used by the neural network.

create_episode - builds one few-shot MAML training episode containing support samples and query samples.

labels - gets the unique attack classes from the dataset.

required_samples - calculates the number of samples needed for each class using the support shot size and query size.

sample selection - randomly selects support and query samples from each class without replacement.

support set - contains the N-shot examples per class used for inner-loop adaptation.

query set - contains separate examples used to calculate the outer-loop training loss.

insufficient samples - raises an error when a class cannot provide the required support samples and at least one separate query sample. The revised episode method can reduce the query size when necessary.

NumPy to PyTorch - converts selected network traffic features and labels into PyTorch tensors and places them on the selected device.

train - trains MAML using multiple few-shot episodes and updates the original network parameters through meta-learning.

meta_batch_size - determines how many episodes are used to calculate each outer-loop update.

meta_epochs - determines how many meta-training iterations are performed.

optimizer - uses Adam to update the original MAML parameters based on the meta-loss. 

evaluate - evaluates the trained MAML model on held-out test samples and calculates accuracy, macro precision, macro recall, macro F1, latency, and throughput.

final adaptation - selects N-shot support examples from the training partition and adapts the model before predicting the test samples.

predictions - uses the adapted MAML parameters to classify network traffic samples into attack categories.

latency - measures the average, median, and worst batch-average prediction time per sample, excluding adaptation time.

throughput - estimates the number of network traffic samples classified per second.

save_model - saves the trained MAML weights, model configuration, input features, label mapping, and feature-scaling information.

device - selects CUDA when a compatible GPU is available; otherwise, it uses the CPU.
