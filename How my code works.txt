Encoder
- Constructor - builds the neural network layers used to create embeddings and classify traffic, stores model settings, sets the random seed, selects CPU or GPU, creates the network, loss function, optimizer, scaler, and data placeholders

- forward - passes input through the encoder and classifier to produce predictions.

- get_embedding - returns the learned embedding representation without using the final classifier.

- prepare_data - selects numeric features, removes invalid values, converts labels to arrays, scales the features, and prepares the training and testing data

- get_feature_columns - finds all numeric input columns except the label column

- train - creates training batches and trains the neural network using cross-entropy loss and the Adam optimizer

- predict - predicts the class labels for one or more input samples

- predict_one - predicts the class label for a single sample

- get_test_data - returns the prepared test features and test labels

- save_model - saves the trained model, model settings, selected features, and scaler information to a file

ProtoNetPrep 

- Constructor - keeps the few-shot episode settings: support shot size, query size, and random seed.

- create_episode - builds one ProtoNet training episode containing support samples and query samples.

- labels - gets all unique class labels from the dataset. Consistency 

- required_samples - calculates how many samples each class needs:
  support samples + query samples.

- class_data - selects all rows belonging to one class.

- sample selection - randomly selects the required number of samples from each class.

- support set - takes the first N samples from each class for the support set.

- query set - takes the remaining selected samples from each class for the query set.

- support_x - keeps the feature values for support samples.

- support_y - keeps the class labels for support samples.

- query_x - keeps the feature values for query samples.

- query_y - keeps the class labels for query samples.

- insufficient classes - skips any class that does not have enough samples for both support and query sets.

- NumPy to PyTorch - combines the selected samples and converts them into PyTorch tensors.

- return values - returns support features, support labels, query features, and query labels for ProtoNet training.

Proto 

constructor - creates the protonet embedding network and stores the input, hidden, and embedding sizes

forward - passes input samples through the embedding network

calculate_prototypes - calculates the mean embedding for each class to create its prototype

calculate_distances - calculates the squared euclidean distance between query embeddings and class prototypes

episode_loss - performs one protonet training episode and calculates the cross-entropy loss

create_targets - converts the original class labels into prototype positions used by the loss function

predict_from_prototypes - predicts each sample by finding the nearest class prototype

embedding - transforms the original network traffic features into a smaller learned representation

support embeddings - embeddings created from the support samples

query embeddings - embeddings created from the query samples

prototypes - average embeddings representing each class

distances - measures how close each query sample is to each class prototype

logits - negative distances used by cross-entropy loss so closer prototypes receive higher scores

ProtoNet Runner 
constructor - stores protonet experiment settings such as shot size, test size, random seed, number of episodes, and learning rate

run - runs the full protonet experiment from dataset preparation to training, evaluation, and saving

prepare_dataset - loads the dataset, cleans it, and encodes the labels

train - trains protonet using multiple few-shot episodes with support and query samples

create_prototypes - creates one prototype for each class from the support samples

evaluate - tests the model and calculates accuracy, precision, recall, f1, latency, throughput, and confusion matrix

get_data_pools - creates or retrieves the training and testing pools for the selected dataset

get_feature_columns - finds the numeric input features used by protonet

create_support_set - selects the n-shot support samples used to build the final class prototypes

create_test_set - selects the test samples used for evaluation

save_model - saves the trained protonet, prototypes, labels, feature information, and experiment settings

protonetprep - creates the support and query sets used during episodic training

protonet - creates embeddings, calculates prototypes and distances, and computes the training loss

evaluator - calculates the final performance metrics and confusion matrix
